## 📝 Cara Menambahkan Diri ke Berkas Ini

Setelah Pull Request (PR) kode, dokumentasi, atau perbaikan bug Anda berhasil disetujui dan di-merge ke branch `main`:

1. Buat branch baru dari `main`:
   ```bash
   git checkout -b docs/add-contributor-<username>
   ```
2. Buka berkas `CONTRIBUTORS.md` dan tambahkan blok tabel kontributor baru di bawah kontributor sebelumnya:
   ```html
   <tr>
     <td align="center" width="160">
       <a href="https://github.com/<username>">
         <img src="https://github.com/<username>.png" width="100px;" alt="<username>" style="border-radius: 50%;" /><br />
         <sub><b>Nama Anda</b></sub>
       </a>
       <br />
       <span title="Kontribusi">💻 📖</span>
     </td>
     <td>
       <strong>Kontribusi & Peran:</strong>
       <ul>
         <li>Ringkasan kontribusi yang telah Anda buat (<a href="https://github.com/myzert/YURIPAY-GOPAY/pull/<nomor_pr>">PR #nomor</a>).</li>
       </ul>
     </td>
   </tr>
   ```
3. Commit dan ajukan Pull Request dengan pesan:
   ```bash
   git commit -m "docs: add @<username> to CONTRIBUTORS.md"
   ```
