## 🤝 Proyek Komunitas untuk Kita Semua

**YuriPay adalah proyek milik komunitas.** Proyek ini hadir, tumbuh, dan terus diperbaiki berkat kolaborasi dari berbagai developer, pegiat open-source, dan merchant Indonesia.

Tidak ada kontribusi yang terlalu kecil. Setiap baris kode, perbaikan dokumentasi (*typo*, tata bahasa, alur panduan), pelaporan celah keamanan atau bug, hingga saran ide fitur baru—**semuanya memiliki peran yang sama pentingnya dalam memajukan proyek ini.**

## 🚀 Siapa Pun Bisa Berkontribusi!

Kami ingin semua orang merasa memiliki proyek ini. Anda bisa berkontribusi dengan:
1. **Memperbaiki Dokumentasi**: Menemukan kalimat yang rancu atau link rusak? Kirim perbaikannya!
2. **Melaporkan Masalah**: Menemukan keanehan saat mencoba login atau checkout? Buka [Issue](https://github.com/myzert/YURIPAY-GOPAY/issues).
3. **Mengajukan Fitur**: Punya ide integrasi baru (misal: webhook Telegram, Discord)? Diskusikan bersama!
4. **Mengirim Kode**: Ambil salah satu issue dan ajukan Pull Request.

👉 **Langkah lengkapnya dapat dibaca di [Panduan Kontribusi (CONTRIBUTING.md)](CONTRIBUTING.md).**

---

## 📝 Mau Nama & Foto Kamu Ditampilkan di Atas?

Setelah Pull Request (PR) kamu di-merge:
1. Buka berkas `CONTRIBUTORS.md`.
2. Tambahkan kolom `<td>` profil GitHub kamu pada tabel di atas.
3. Kirimkan PR dengan judul: `docs: tambah @username ke daftar kontributor`.
4. Nama dan foto profil kamu akan otomatis terpampang secara bangga di halaman ini!
